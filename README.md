<h2 align="center"><b>👨‍💻 About Me</b></h2>

<div align="center">

I'm a **backend software engineer** working in **Java and Spring Boot**, with hands-on experience building backend systems in a banking environment.

I care about the parts of a backend that only show up once it's running for real: **transaction integrity**, **idempotency**, **failure handling**, **authorization boundaries**, **auditability** and **visibility into what the system is doing**. I design for failure: every remote call has a timeout, every retry has a reason and a bound, and every payment-changing command is safe to repeat.

My focus is **event-driven, security-conscious financial backends**: modular architectures built around clear domain boundaries, **PostgreSQL** transactions with the **outbox pattern** feeding **Kafka**, secured with **OAuth2/OIDC**, tested with **Testcontainers**, deployed through **CI/CD** to **AWS** and **Kubernetes**, and instrumented with **Prometheus and Grafana**.

I learn by building **production-style systems** rather than following tutorials end to end, and I document the trade-offs behind my decisions.

</div>
